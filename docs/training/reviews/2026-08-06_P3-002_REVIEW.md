## 7. Findings

### Finding 1 — Duplicate name conflict maps to slug error

- Severity: P2 — SHOULD FIX
- Location: `apps/api/src/modules/organizations/organization.service.ts:24`
- Requirement: Duplicate slug returns `ORGANIZATION_SLUG_EXISTS`; errors should not mislabel a different unique field.
- Hiện tượng: `isUniqueError(error)` maps any Prisma `P2002` to `ORGANIZATION_SLUG_EXISTS`.
- Nguyên nhân: The repository helper does not inspect `error.meta.target` for `slug` versus `name`.
- Rủi ro: Duplicate organization name can return misleading slug error; client may highlight the wrong field.
- Hướng sửa: Inspect unique target and map `slug` to `ORGANIZATION_SLUG_EXISTS`; either map `name` to a separate conflict code or make name non-unique in a future DB task if uniqueness is not desired.
- Test kiểm chứng: Add duplicate-name API test if name uniqueness remains part of contract.
- Command chạy lại: `DATABASE_URL=postgresql://thesiflow:12345678@localhost:5433/thesiflow?schema=public npm run test --workspace apps/api -- tenancy/organization-create-activate.test.ts`

### Finding 2 — Non-member activation of active organization returns already-active before membership authorization

- Severity: P2 — SHOULD FIX
- Location: `apps/api/src/modules/organizations/organization.service.ts:39`
- Requirement: Activation should be authorized by creator/provisioning membership before state details matter.
- Hiện tượng: If an organization is already active and actor has no inactive creator membership, service returns `ORGANIZATION_ALREADY_ACTIVE` rather than `ORGANIZATION_ACTIVATION_FORBIDDEN`.
- Nguyên nhân: Branch checks `organization.status === "active"` before distinguishing whether the actor owns the activation right.
- Rủi ro: Authenticated non-members can learn active/existing organization state through activation endpoint.
- Hướng sửa: Prefer membership/authorization failure before active-state conflict for actors without creator membership; keep `ORGANIZATION_ALREADY_ACTIVE` only for authorized creator retry.
- Test kiểm chứng: Add test where another active account calls activate on an already-active organization and expects `403`.
- Command chạy lại: `DATABASE_URL=postgresql://thesiflow:12345678@localhost:5433/thesiflow?schema=public npm run test --workspace apps/api -- tenancy/organization-create-activate.test.ts`
