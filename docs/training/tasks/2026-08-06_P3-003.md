## 8. Giải thích database design

- Invitation là record riêng vì membership chỉ sinh ra khi đúng account accept.
- Raw token không lưu DB; service hash token để lookup.
- Partial unique pending organization/email chặn spam duplicate pending invite.
- `acceptedAt` chứng minh state transition đã xảy ra.
- Accept phải transaction: update invitation accepted + create membership active cùng lúc.
- Unique membership guard xử lý race hai accept đồng thời.

## 9. Backend implementation developer phải làm

Developer cần mở rộng organization module hoặc tạo membership invitation module tối thiểu:

- Schema:
  - `createInvitationSchema`: `{ email }`, email valid, normalized lowercase.
  - `acceptInvitationSchema`: `{ token }`, non-empty string.
- Routes:
  - `POST /organizations/:organizationId/invitations`
  - `POST /membership-invitations/accept`
- Service:
  - Reuse/extract bearer auth guard from organization service.
  - Verify inviter has active membership in organization.
  - Create invitation token, store `tokenHash`, `status=pending`, `expiresAt` default 7 days.
  - Accept: verify active account, hash token, find invitation, check pending/not expired, compare account.email with invitation.email.
  - Transaction create membership + mark invitation accepted.
- Repository:
  - `createMembershipInvitation(input)`.
  - `acceptMembershipInvitation(input)`.
  - Map unique conflicts.
- Mapper:
  - Return safe invitation DTO, never `tokenHash`.
  - P3-003 test expects `invitationToken` in response so developer can deliver token in test/demo scope. Do not persist raw token.

Expected domain errors:

- `AUTH_REQUIRED` → 401.
- `ORGANIZATION_NOT_FOUND` → 404.
- `ORGANIZATION_MEMBERSHIP_REQUIRED` → 403 if inviter lacks active membership.
- `MEMBERSHIP_INVITATION_NOT_FOUND` → 404 for invalid token.
- `MEMBERSHIP_INVITATION_NOT_PENDING` → 409 for replay/non-pending invitation.
- `MEMBERSHIP_INVITATION_EXPIRED` → 410 for expired invitation.
- `MEMBERSHIP_INVITATION_RECIPIENT_MISMATCH` → 403 for wrong account.
- `TENANT_MEMBERSHIP_ALREADY_EXISTS` → 409 for duplicate membership.

## 10. API contract

### POST /organizations/:organizationId/invitations

Authentication: Required bearer access token. Actor must have active membership in organization.

Request:

```json
{
  "email": "Student@Example.Test"
}
```

Success: `201 Created`

Response:

```json
{
  "data": {
    "invitation": {
      "id": "uuid",
      "organizationId": "uuid",
      "email": "student@example.test",
      "status": "pending",
      "expiresAt": "ISO-8601"
    },
    "invitationToken": "opaque-token"
  }
}
```

Never return `tokenHash`.

### POST /membership-invitations/accept

Authentication: Required bearer access token. Account email must match invitation email.

Request:

```json
{
  "token": "opaque-token"
}
```

Success: `200 OK`

Response:

```json
{
  "data": {
    "invitation": {
      "id": "uuid",
      "organizationId": "uuid",
      "email": "student@example.test",
      "status": "accepted",
      "acceptedAt": "ISO-8601"
    },
    "membership": {
      "id": "uuid",
      "accountId": "uuid",
      "organizationId": "uuid",
      "status": "active",
      "source": "invitation",
      "activatedAt": "ISO-8601"
    }
  }
}
```
