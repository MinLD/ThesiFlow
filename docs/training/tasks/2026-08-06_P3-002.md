## 8. Giải thích database design

- Create để `Organization.status = disabled` nhằm tách creation khỏi activation.
- `verifiedAt = null` trước activation, set ISO timestamp sau activation.
- Creator membership bắt đầu `inactive`, để P3-001 invariant bảo đảm inactive membership không tạo tenant context.
- Activate chuyển membership sang `active`, set `activatedAt` trong cùng transaction với organization activation.
- Unique slug ở DB là guard cuối cùng chống race; service phải map duplicate thành `ORGANIZATION_SLUG_EXISTS`.

## 10. API contract

### POST /organizations

Authentication: Required bearer access token.

Request:

```json
{
  "name": "APLP Demo Faculty",
  "slug": "aplp-demo-faculty"
}
```

Success: `201 Created`

Response:

```json
{
  "data": {
    "organization": {
      "id": "uuid",
      "name": "APLP Demo Faculty",
      "slug": "aplp-demo-faculty",
      "status": "disabled",
      "verifiedAt": null
    },
    "membership": {
      "id": "uuid",
      "accountId": "uuid",
      "organizationId": "uuid",
      "status": "inactive",
      "source": "provisioning"
    }
  }
}
```
